# Исправления аудита v3 и планета — 20.10.2026

Исходный аудит: `ev-option-grid-audit-v3.md` от 20 октября. Исправления выполнены поверх опубликованной версии с планетой и заметной кнопкой демонстрационного сценария. Расчётное API — версия 0.3.1.

## Планета

- Москва выделена в центре: 24 башни, включая пару высотных башен, золотую башню и закрученный объём. Шесть меньших городов содержат по семь зданий. Это художественная схема, а не карта географии/измеренных потоков.
- Шесть направленных потоков идут от Москвы к городам. Сине-фиолетовые цвета переходят в красно-оранжевые по мере прокрутки.
- Исправлена причина скачков теней: ранее неподвижная мировая карта теней пересчитывалась через 0,055 радиана. Теперь источник света и камера теней вращаются вместе с планетой, а матрица проекции обновляется каждый кадр. Глубина статичной сцены вычисляется один раз и после восстановления WebGL. Инвариантность локальной проекции проверяется математическим тестом.
- Архитектура объединена по материалам; окна инстансированы. Сохранены ограничение числа пикселей, отложенная загрузка, остановка вне экрана, пауза, reduced-motion и восстановление контекста. Информационная карточка находится за пределами планеты.

## Регрессии N1–N5

- N1: один финансовый вердикт для 2D-рейтинга, выбранной площадки и HTML-отчёта. Отдельно указаны результаты при спросе 100% и 50%; положительная база сама по себе не превращается в разрешение строить.
- N2: верхняя панель доступна при открытых разделах. Смена года/сценария обновляет раздел, сохраняет его открытым и не отбирает фокус у панели. На телефоне панель не перекрывается листом.
- N3: пример ×1,5 сохраняет сценарий роста; постоянный индикатор масштаба и сброс доступны над картой и всеми разделами.
- N4: текст, число и цвет индикатора роста используют один индекс к 2026 году.
- N5: URL и API принимают инвестиционные решения только 2027/2030. Кнопки и действия соблюдают те же даты. Годы наблюдения 2026/2035 остаются доступны.

## Остальные исправления

- Двухэтапный анализ: выбор станции, все 28 пакетов (включая все восемь одиночных действий), текущий масштаб и отдельная проверка ×1,5; положительные значения гибкости перечисляются явно, нулевые не подменяются. Выполняется в Worker, есть прогресс и отмена.
- Завершённый пустой подбор больше не сопровождается повторным предложением запустить его. При изменении масштаба/сети сообщение прежнего подбора сбрасывается.
- Пороги риска очереди и статуса загрузки согласованы: 50%/80%. Денежная модель отказов и отдельный условный эталон M/M/c сохраняются.
- Основные показатели экономики и загрузки используют выбранный сценарий; таблица сравнения базовых ЧПС явно подписана.
- Разделены граница смены всего плана и безубыточность расширения выбранной станции. Конец шкалы мощности подписан в МВт и процентах лимита.
- Из активных станций Хаффа удалены `sessions`, `avgMin`, `sens`. Время сессии берётся из общего исследовательского допущения. Старый формат API без Хаффа по-прежнему требует собственные параметры.
- Отладочные `__ev`, `__act`, `__demo`, `__teleport`, `__types` публикуются только при `?debug=1`. Штатные действия используют модульные функции; интерфейс не зависит от глобалов. Это режим диагностики, а не граница безопасности.
- Помощник не выбирает ZIL-01 без указания пользователя, объясняет сетевой критерий и может рассчитать численную границу спроса с тем же алгоритмом. Результаты кэшируются; для расширенных наборов свыше шести станций направляет к Worker. Программные имена заменены русскими обозначениями.
- В 2D вечерний/маятниковый профили имеют ночной провал и нормированы к прежнему общему спросу. Подписи «Спрос 50%» отличаются от сценариев роста 3D. Рейтинг оговаривает неопределённость пространственных весов; близкие результаты до 5% отмечаются отдельно.
- При отсутствии мощности у Supercharger/известного DC-разъёма используется явно отмеченное сценарное допущение 50 кВт. Явный тег мощности сохраняется; Tesla Destination автоматически быстрой станцией не считается. Реестр и генератор исправлены.
- Некорректный JSON расчётного API получает русскую ошибку.

## Что требует фактических данных

Это ограничения модели, а не исправляемые программной правкой дефекты:

- Тариф 24 ₽, сметы, сроки и резервы остаются явно обозначенными сценарными параметрами. Точка безубыточности не подставляется вместо реального тарифа. Публичный сайт оператора не дал проверяемой цены именно для модельных адресов; для подтверждения нужны данные приложения/условия оператора.
- Якорь загрузки 10%, качество валидации AUC 0,407 и постоянный индекс после 2031 раскрыты на сайте. Новых наблюдений не появилось; числа не подгонялись под инвестиционный вывод.
- Совпадения собственных модельных станций и конкурентов по близости остаются кандидатами на проверку. Без подтверждённых идентификаторов/владения удалять объекты из конкуренции нельзя.
- Основной автоматический подбор остаётся ограниченным робастным алгоритмом. Двухэтапная оценка показана отдельно с явным допущением об информации в 2030. Превращать её в новую основную стратегию без независимой проверки не стали.
- Индикатор мощности при полной одновременности не заменяет мгновенную модель зарядных кривых и технические условия.
