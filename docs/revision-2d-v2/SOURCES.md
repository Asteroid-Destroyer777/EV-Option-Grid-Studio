# Источники этой ревизии

## География

- [OpenStreetMap Moscow extract / BBBike](https://download.bbbike.org/osm/bbbike/Moscow/): файл `Moscow.osm.pbf`, 85 028 149 байт; Last-Modified 10.10.2026. Из него построены локальные тайлы, включая здания, дороги, воду, существующие зарядные объекты, парковки и точки интереса. © участники OpenStreetMap, ODbL. Производный набор и manifest включены в проект; исходный PBF и среда подготовки исключены из ZIP. Скрипт воспроизведения — `tools/build_moscow_tiles.py`.
- [OpenStreetMap copyright / ODbL](https://www.openstreetmap.org/copyright).
- [Публичные экземпляры Overpass](https://wiki.openstreetmap.org/wiki/Overpass_API#Public_Overpass_API_instances): maps.mail.ru, overpass.private.coffee, overpass-api.de. Во время сетевой проверки были ошибки 504/429/406; их наличие в списке не означает гарантированную доступность.
- Пример Казани: разовая выгрузка OpenStreetMap API для `[55.783,49.112,55.793,49.132]`, 12.10.2026. Полная relation канала Булак добавлена до нормализации. Имена редакторов и uid исключены. API редактирования OSM не используется как источник в рабочем приложении.

## Галерея оформления

- Реальная ночная фотография Москвы-Сити: [Moscow City at night, 2024 04](https://commons.wikimedia.org/wiki/File:Moscow_City_at_night,_2024_04.jpg), MBH, 09.10.2024, CC BY-SA 4.0. Используется в D1 на главном экране, локальная версия 3840 × 2880. Изменения: CSS-кадрирование и тонирование. Атрибуция и ссылка на CC BY-SA 4.0 присутствуют на странице. Производная композиция фотографии сохраняет ту же лицензию; программный код имеет собственную лицензию проекта.
- Tesla и текущая дневная фотография города: происхождение сохранено в [документации предыдущей ревизии](../revision-2026-10-12/SOURCES.md). Макеты не подтверждают разрешение на коммерческое распространение всех брендовых материалов.
- Бобр и технический референс внутренностей Tesla переданы пользователем. Бобр используется в помощнике и сцене ожидания; техническая картинка — в выбранном B4 и макетах B. Точность заводской компоновки по ней не установлена.
- [Charles Leclerc](https://charlesleclerc.com/en/), [Lando Norris](https://landonorris.com/), [ReactBits Ballpit](https://reactbits.dev/backgrounds/ballpit), [21st.dev](https://21st.dev/) — ориентиры взаимодействия, не источники контента проекта. Доступность текстовых страниц не считается проверкой всех их анимаций. Нативная анимация сайта сделана в существующем стеке без установки React-компонентов.

Демонстрационный спрос ЗИЛ и параметры экономики в `data/district-demo.json` являются синтетическими. В районных тестах также используется синтетический спрос на реальной географии.
