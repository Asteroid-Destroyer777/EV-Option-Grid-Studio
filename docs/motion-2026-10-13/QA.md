# EV-Option Grid — motion revision, 13.10.2026

## Изменения

- Кабели: уменьшена толщина оболочки, убраны массивные металлические крепления, добавлены световые импульсы, которые проходят по реальной SVG-геометрии кабеля. Свечение усиливается при зарядке.
- Tesla: начинается за правой границей экрана, колёса вращаются пропорционально пройденному расстоянию. Маски дисков и центры вращения исправлены по исходной фотографии; при остановке диски приходят в исходную ориентацию. Добавлены фары и подсветка станции.
- Круглое раскрытие внутренностей сохранено; исключающие маски колёс и контур кузова уточнены.
- Сцена Крути в 2D: два присланных пользователем кадра, движение камеры, диагональный переход, пульсация кабеля и разъёма. Минимальная длительность показа — 7000 мс. Если вычисление идёт дольше, сцена остаётся видимой. Фактический прогресс вычисления показывается отдельно; цифра 80% на художественном кадре не является прогрессом расчёта. Это композиция на основе изображений, а не новая покадровая анимация персонажа.
- Инвестиционная история: карта и неоновая линия теперь используют общий координатный контейнер; линия соединяет основания маркеров. Исправлены отступы между карточкой, подписью и шкалой лет.
- Убрана видимая надпись «Фото: MBH · CC BY-SA 4.0» поверх главной сцены. Автор, лицензия и ссылки сохранены в доступном разделе источников.
- Исправлено горизонтальное переполнение формы 2D на мобильном экране. Все исходные поля и расчёты сохранены.

## Запуск

Нужен Node.js 20 или новее. В распакованной папке проекта выполнить:

```sh
npm start
```

Открыть `http://localhost:5173/`. Дополнительные зависимости устанавливать не требуется.

Пользовательские API-ключи и `.env.local` в ZIP не входят. Для серверного диалога помощника настроить собственную локальную `.env.local` по имеющемуся `.env.example`. Локальная рабочая копия пользователя сохранена вместе с её настройками; ключи в публичный клиент не добавлены.
