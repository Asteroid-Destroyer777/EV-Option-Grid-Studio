Крутя в действии.
Четыре варианта сцены.

Собственная анимация персонажа: отдельные руки, голова, ноги и хвост. Никаких сменяющихся фотографий. Это варианты для выбора; рабочий расчёт остаётся прежним.

0,0 / 7 с
K1 / Крутя подключает ЭЗС7 секунд

Полный план. Подходит, берёт кабель двумя руками, вставляет разъём. Затем загораются станция и кабель.

Подход → подключение → зарядка
K2 / Крупный план подключения7 секунд

Камера ближе к персонажу и рукам. Плавный наклон, точное движение разъёма, световой отклик контакта.

Захват → контакт → свет
K3 / Крутя исследует район7 секунд

Работает с картой: контур замыкается, площадки появляются по очереди, лучший вариант выделяется.

Контур → сравнение → площадка
K4 / Крутя запускает сеть7 секунд

Низкий ракурс и подключение. Энергия проходит снизу к ЭЗС, затем загораются точки городской сети.

Подключение → сеть → город
